# Web 端共享契约补充需求

本文记录 Web 收口过程中发现的跨端契约缺口，仅作为后续共享层评审输入。本次未修改 Android、`packages/*` 或后端实现。

## 需要共享的接口能力

| 能力 | Web 当前适配 | 建议共享契约 |
| --- | --- | --- |
| 身份认证 | `AuthService` | 账号认证、会话过期时间、角色与数据范围；开发身份必须与正式认证接口隔离 |
| 培训方案 | `TrainingPlanService` | 候选方案列表、方案版本、重新规划原因、幂等键、对应 Agent Run |
| 培训报告 | `ReportService` | 报告状态、版本、完整性检查、确认人/时间、异步导出操作 ID |
| Agent 运行 | `AgentRunService` | 运行详情、事件流、检查点、有限重试、回退、人工接管与可恢复性 |

## 建议补充的公共字段

- 所有正式写接口：`idempotencyKey`、`requestId`、`actorId`、`occurredAt`。
- 版本化业务对象：`version`、`snapshotId`、`updatedAt`、`updatedBy`。
- 列表接口：游标或页码、`pageSize`、`total`、稳定排序字段。
- 异常对象：稳定错误码、用户可读说明、`retryable`、建议动作、关联 `traceId`。
- 审批对象：风险摘要、证据引用、影响范围、当前责任人、等待时长、决定后果。
- Agent 事件：事件类型、运行 ID、节点 ID、检查点 ID、重试次数、恢复位置、是否发生正式写入。

## 兼容与治理要求

1. Web 业务视图只消费脱敏业务摘要；模型、Prompt、Token 等字段只对系统管理员诊断视图开放。
2. 旧任务必须保持创建时的知识、规则、方案和审批快照，新版本不得静默覆盖。
3. 高风险写入在审批前返回可恢复暂停状态，不能只返回通用失败。
4. 事件类型和状态枚举采用向后兼容扩展；未知值由客户端降级为“状态更新中”，不得误判为成功。
5. 正式适配器接入后，Web 页面保持通过 service/store 读取，不直接依赖测试数据包。
