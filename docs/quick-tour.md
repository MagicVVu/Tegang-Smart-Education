# 3 分钟导览

## 一句话定义

管理员提供培训目标和约束，系统基于员工与部门信息完成诊断、知识检索、计划、辅导和测评，再依据结果重规划、补训或提交审批，最终形成可追溯报告与执行轨迹。

## 首个黄金流程

管理员下发新员工入职培训目标 → 系统读取组织与画像 → 前测诊断 → 基于证据生成个性化计划 → 必要时人工审核 → 对话式培训 → 自适应测评 → 更新画像 → 补训/复测/重规划/审批 → 生成报告与 Trace。

## 差异化证明

智信部和炼钢生产部接收同一入职目标时，应因部门知识、风险、员工画像和测评结果不同，形成可解释的不同内容、案例、题目、顺序与干预，而不是两套前端写死流程。

## 控制边界

- 权限、部门隔离、审批阈值和数据外发规则由硬约束控制。
- 无充分证据时拒答或请求补充资料。
- 高风险写操作必须事前审批。
- 培训结果不能直接用于转正、晋升、处罚或绩效决策。
- 模拟资料和数据必须明确标注。
