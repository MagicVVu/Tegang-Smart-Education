# ADR-0001：建立规划阶段 Monorepo 导航骨架

- 状态：Accepted
- 日期：2026-07-23

## 背景

项目需要一个可克隆、可导航、可持续进行 Git 操作的公开仓库，但当前仍处于规划与研究准备阶段，尚未批准具体技术栈或核心系统实现。

## 决定

建立单仓库、多职责目录的导航骨架。代码域只记录职责、边界和进入条件；不创建会预设框架、数据库、RAG 或 Agent 编排方案的大量代码。

同时建立 README、docs 导航、状态看板、环境示例、Git 约定、任务/风险/证据台账和最小无依赖 CI。

## 影响

- 新贡献者可以快速理解项目和后续材料位置。
- 后续任务可以在不重构仓库导航的情况下逐域推进。
- 目录名称不代表部署边界，具体模块映射仍需后续决策。

## 复核条件

当正式架构方案和首个可运行版本范围获批时，复核目录职责、开发命令和 CI 检查。
