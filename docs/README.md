## 文档状态标记

- `Draft`：草案，不能作为实现依据。
- `In Review`：评审中，仍可能变化。
- `Approved`：已批准，可作为当前范围的实现依据。
- `Superseded`：已被新版本替代，保留用于追溯。

若当前任务、已批准文档、仓库现状和背景说明发生冲突，应按该顺序处理，并明确记录冲突。
