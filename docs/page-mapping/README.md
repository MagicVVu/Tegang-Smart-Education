# 页面与 PRD 映射

| PRD 页面 | Web/移动实现 | 主要角色 | 核心任务 |
| --- | --- | --- | --- |
| P-00 登录与身份入口 | `/login`、移动 `Login` | 全部角色 | 建立角色会话，不用页面隐藏代替权限 |
| P-01 工作台/首页 | `/admin/dashboard`、移动 `Home` | 管理员、员工 | 查看当前优先任务、异常和下一步 |
| P-02 培训目标创建 | `/admin/training/create` | 培训管理员 | 分步录入目标、对象、约束与风险要求 |
| P-03 方案查看与调整 | `/admin/plans/:taskId` | 培训管理员 | 比较候选、查看引用、确认或重规划 |
| P-04 学习与辅导 | 移动 `Learning`、`Tutor` | 员工 | 学习部门路径、查看引用、智能辅导 |
| P-05 测评/结果/补训 | 移动 `Assessment`、`AssessmentResult`、`Remedial` | 员工 | 测评、高风险独立判定、补训与复测 |
| P-06 审批中心 | `/approvals`、`/approvals/:taskId` | 审核员；管理员只读 | 批准、修改后批准、拒绝、退回补充 |
| P-07 培训报告 | `/admin/reports/:taskId` | 管理员、审核员 | 查看完成、测评、补训、风险和异常 |
| P-08 Agent 运行中心 | `/agent-runs/:taskId` | 管理员、审核员、系统管理员 | 业务证据视图与开发者 Trace 隔离 |
| P-09 知识与系统配置 | `/system/knowledge` | 系统管理员 | 查看知识版本、权限和规则边界 |

## 角色导航

- 员工：移动首页、培训、智能辅导、消息、我的。
- 培训管理员：工作台、新建培训、方案与任务、培训报告、Agent 运行中心。
- 审核员：审批中心、培训报告、Agent 业务证据。
- 系统管理员：知识与配置、开发者 Trace。

路由守卫、数据服务和按钮权限共同执行权限控制。无权限时进入正式的受限页面。
